# Create GitHub Repository

1. Open your web browser and go to: https://github.com/new

2. Fill in these details:
   - Repository name: `my_food2_app`
   - Description: "React Native application with AWS Amplify Gen 2 and email authentication"
   - Visibility: Public
   - Do NOT initialize with:
     - README
     - .gitignore
     - license

3. Click "Create repository"

4. After creating the repository, come back to your terminal and we'll push the code.

The remote is already configured with your authentication token, so once you create the repository, let me know and I'll help you push the code.
